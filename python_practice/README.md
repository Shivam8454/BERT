# Python Practice Exercises

Welcome to your Python practice environment! This repository contains exercises organized by difficulty level to help you improve your Python programming skills.

## Directory Structure

- `basics/` - Fundamental Python concepts
- `intermediate/` - Object-oriented programming and data structures
- `advanced/` - Advanced Python features and patterns
- `solutions/` - Solutions with detailed explanations

## How to Use

1. Start with the basics if you're new to Python
2. Work through exercises in order within each directory
3. Try to solve each problem before looking at solutions
4. Run your code to test it: `python filename.py`
5. Compare your solution with the provided ones

## Exercise Categories

### Basics
- Variables and data types
- Control structures (if/else, loops)
- Functions and scope
- Basic input/output
- String manipulation
- List and dictionary operations

### Intermediate
- Object-oriented programming
- File handling
- Error handling and exceptions
- Data structures (sets, tuples)
- List comprehensions
- Modules and packages

### Advanced
- Decorators and closures
- Generators and iterators
- Context managers
- Async programming
- Regular expressions
- Design patterns

## Getting Started

Run the setup script to check your Python environment:

```bash
python python_practice/check_setup.py
```

Then start with the first exercise:

```bash
python python_practice/basics/01_variables.py
```

Happy coding! 🐍
